# Agent Hackathon Project Pack

This folder contains practical project ideas and build plans for a hackathon-style initiative where AI agents do most implementation work with human approval gates.

## Contents
- `TOP_10_IDEAS.md`: ten real-world ideas suitable for agent-assisted build.
- `SELECTED_PROJECT_EXECUTION_PLAN.md`: detailed execution plan for one recommended project.
- `AGENT_WORKFLOW_AND_TOOLS.md`: role-based agent workflow, toolchain, and delivery gates.
- `PITCH_DECK_OUTLINE.md`: ready-to-present internal pitch structure for org leadership.

## How to use this pack
1. Pick one idea from `TOP_10_IDEAS.md`.
2. Copy and adapt the selected project plan timeline.
3. Use `AGENT_WORKFLOW_AND_TOOLS.md` as your operating model.
4. Present with `PITCH_DECK_OUTLINE.md`.
