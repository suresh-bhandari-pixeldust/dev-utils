# dev-utils

Utilities, scripts, and templates for day-to-day development workflows.

## Repository structure
- `AGENTS.md` — guidance for coding agents working in this repository.
- `.github/PULL_REQUEST_TEMPLATE.md` — standard pull-request checklist.
- `.github/ISSUE_TEMPLATE/task.md` — lightweight task template.

## Getting started
1. Clone the repository.
2. Create a branch for your change (`feat/*`, `fix/*`, `chore/*`, or `docs/*`).
3. Make focused updates and include validation notes in your PR.

## Contributing
- Keep changes small and scoped.
- Add usage examples when introducing a new utility.
- Run available checks before committing.

## Current status
This repository is intentionally minimal and ready for agent-managed development.
