# dev-utils

Utilities and templates for day-to-day development workflows.

## Repository structure
- `AGENTS.md`: instructions for coding agents working in this repository.
- Future scripts and helpers should be added in focused folders and documented here.

## Getting started
1. Clone the repository.
2. Create a branch for your change.
3. Follow `AGENTS.md` guidance and update documentation with any new utility.

## Contributing
- Keep changes small and focused.
- Add usage examples when introducing a new tool.
- Document validation steps in pull requests.
